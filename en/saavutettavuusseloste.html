Accessibility

Accessibility statement

This statement concerns the seniorclub.fi website and was prepared when the site was published.

Compliance status

We have aimed to design and build this website in line with the EU Web Accessibility Directive (2016/2102) and Finland's Act on the Provision of Digital Services, applying the WCAG 2.1 level AA criteria. This statement is currently based on a self-assessment carried out during the build of the site — an external accessibility audit has not yet been commissioned. The statement will be updated once a more comprehensive accessibility test has been carried out.

What we have done for accessibility

  • The site is available in three languages (Finnish, English, Russian), with the correct language attribute on every page and clear links to the other languages.
  • Pages include a "Skip to content" link so keyboard users can jump straight to the main content.
  • The Schedule page's table does not require horizontal scrolling on mobile — on small screens the information is shown as cards instead.
  • The contact form's success and error messages are marked up so screen readers announce them automatically (aria-live), and focus moves to the message after submission.
  • The menu can be operated with a keyboard, and the state of its submenus is announced (aria-expanded).
  • Images have descriptive alternative text, and decorative images are marked so screen readers skip them.
  • Colours and fonts were chosen with contrast and readability in mind, and text size can be increased using the browser's own settings without breaking the layout.

Known gaps

We have not yet commissioned a full, external WCAG 2.1 AA audit, so some gaps may not yet have been identified. This statement will be updated after that audit.

Found an accessibility issue?

We're happy to tell you more about the site's accessibility, and we welcome feedback if any part of the site is not accessible to you.

  • Email: seniorclub@seniorclub.fi

Enforcement authority

If you are not satisfied with the response you receive, or receive no response within two weeks, you can report the matter to the Regional State Administrative Agency for Southern Finland. Their website explains exactly how to submit a report and how it will be handled.

  • Regional State Administrative Agency for Southern Finland, Accessibility Supervision Unit
  • Website: saavutettavuusvaatimukset.fi
